
Промпт для генерации проекта:

Напиши CLI-приложение на Python для хранения паролей с шифрованием, используя SQLite3.
Требования:

При первом запуске программа должна запросить пароль входа, сохранить его в базе данных в виде хеша SHA-256.

При последующих запусках программа требует этот пароль для входа.

Все хранимые данные — в формате:

Название/откуда (например, "Google")

Логин

Пароль (в зашифрованном виде)

Для шифрования паролей используй Fernet из библиотеки cryptography.

Ключ для шифрования хранить локально в файле .key (если файла нет — генерировать при первом запуске).

Команды CLI:

add — добавить новую запись

get — получить пароль по названию (после ввода мастер-пароля)

list — показать список всех сохранённых записей (названия и логины)

delete — удалить запись по названию

new - создать новый пароль

Все данные хранятся в SQLite3, при старте проверять наличие таблиц и при необходимости создавать.

Код должен быть структурирован — функции для БД, функции для шифрования, основной CLI-обработчик.

При первом запуске приложение запросит мастер-пароль.

Переходим в файл password_manager.py

Кода достаточно много, поэтому разберём основные классы.



Класс DatabaseManager

Отвечает за взаимодействие с базой данных.

В методе __init__ создаётся файл базы.

Функция init_database инициализирует таблицы. Есть отдельная таблица для мастер-пароля.

Мастер-пароль хранится в виде хэша.

✅
Хэш — это как цифровой отпечаток пальца для информации.

Берём любой текст, файл, картинку или пароль → пропускаем через специальный алгоритм → на выходе получаем набор символов (обычно цифры и буквы).
Этот набор всегда одинаковый для одного и того же входа.
Но если поменять хоть одну букву или пиксель — хэш будет совсем другим.
Пароли никогда не хранятся в открытом виде, так как это небезопасно.

При вводе нового пароля он преобразуем в хэш и сравнивается с уже сохранённым хэшем.

Основные функции:

set_master_password, get_master_password — установка и проверка мастер-пароля.
add_password — добавление новой записи.
get_password — получение пароля по названию.
list_passwords — вывод списка всех паролей.
delete_password — удаление записи.


Класс EncryptionManager

Управляет шифрованием и дешифрованием.

В методе __init__ проверяется наличие файла ключа (.key):

если он есть — ключ считывается;
если его нет — ключ создаётся.
Методы:

encrypt — шифрование данных;
decrypt — дешифрование данных.
Всё реализовано через библиотеку cryptography и модуль fernet.



Класс PasswordGenerator

Отвечает за создание надёжных паролей.

Именно через этот класс пользователь взаимодействует с приложением.

По умолчанию длина — 16 символов.

Параметры: использовать заглавные буквы, строчные, цифры, спецсимволы.

На основе этих параметров формируется строка доступных символов.

Пароль генерируется случайным образом.

Основные функции:

setup_master_password — установка мастер-пароля, если его нет.
authenticate — аутентификация.
add_password — добавление нового пароля.
generate_password_interactive — генерация пароля.
get_password — получение пароля по названию.
list_passwords — список всех записей.
delete_password — удаление записи.
show_menu — показ меню.


Запуск и работа

Запускаем через три точки — Terminal — New Terminal.

Активируем виртуальное окружение. В Windows команда:
venv\Scripts\Activate.ps1
Запускаем приложение командой:
python .\password_manager.py
При первом запуске нужно установить зависимости.
Если запуск не первый, программа сразу запросит мастер-пароль.
Ввод мастер-пароля реализован с помощью функции getpass. В отличие от input, она скрывает вводимые символы (они не отображаются). Это безопаснее.
Пример работы

Вводим мастер-пароль
Добавляем запись: название и логин.
Пароль генерируется автоматически.
Выбираем параметры генерации:
длина 16 символов (до 64);
заглавные буквы — да;
строчные буквы — да;
цифры — да;
спецсимволы — да.
Пароль можно скопировать в буфер обмена (если добавить поддержку библиотеки для копирования).
Просмотр списка всех паролей показывает добавленную запись.
Получение пароля по названию выводит логин и пароль.
Можно также получить пароль для других аккаунтов, например, Google.
Удаление записи: команда удаляет пароль ya. После проверки в списке этой записи уже нет.
Если удалить файлы .key и password.db, то при следующем запуске приложение создаст их заново и сразу попросит ввести новый мастер-пароль.При этом база будет пустой, так как старые данные утеряны.
